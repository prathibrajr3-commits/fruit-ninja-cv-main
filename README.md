# 🍉 AI Fruit Ninja Game

A modern Fruit Ninja-style browser game built using React, TypeScript, Vite, Tailwind CSS, and MediaPipe Hand Tracking.

## 🚀 Features

- ✋ Real-time hand tracking using webcam
- 🍎 Slice fruits using finger gestures
- 💥 Bomb collision system
- 🔥 Combo scoring effects
- 🔊 Real slicing sound effects
- 🎮 Dynamic difficulty scaling
- ⚡ Smooth canvas animations
- 📱 Responsive UI
